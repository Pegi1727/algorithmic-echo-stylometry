6. APA-STYLE SUMMARY SENTENCE (ready to paste)
----------------------------------------------
A repeated-measures ANOVA with Greenhouse–Geisser correction (ε = .54) indicated
a significant effect of time on scores, F(1.08, 31.33) = 272.25, p < .001,
partial η² = .90. Bonferroni-corrected pairwise comparisons showed significant
increases from T1 to T2 (M_diff = 5.20), t(29) = 14.84, p < .001, dz = 2.71,
and from T2 to T3 (M_diff = 4.80), t(29) = 15.75, p < .001, dz = 2.88, with the
largest change between T1 and T3 (M_diff = 10.00), t(29) = 17.26, p < .001,
dz = 3.15. Between-group analyses revealed that total drift (T3−T1) differed
significantly across profiles, F(2, 27) = 60.94, p < .001, η² = .82, with the
High profile (M = 13.55, SD = 1.92) showing greater drift than Moderate
(M = 8.57, SD = 0.85) and Stable (M = 6.20, SD = 1.30), all Tukey ps ≤ .008.
Baseline scores also differed across profiles, F(2, 27) = 9.64, p < .001, η² = .42,
the High profile starting lower. Baseline was strongly and negatively correlated
with total drift, r(28) = −.77, p < .001, indicating that lower initial scores
were associated with greater subsequent change.

CAVEATS
-------
- Mauchly's test and Levene's test were violated in places; GG correction applied
  for sphericity. Welch/robust alternatives would strengthen the between-group claim,
  though effect sizes are very large.
- Cohen's dz uses within-subject SD; d_av uses the averaged SD of the two time points.
- Effect-size benchmarks: η² ≈ .01 small, .06 medium, .14 large (Cohen, 1988).
